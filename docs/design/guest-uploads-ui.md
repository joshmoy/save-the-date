# Guest uploads UI

Direction: extend Harbour’s calm operational forms. Guests should understand access, limits, consent, private processing and owner review before sharing. Owner controls explain event/album scope and single-purpose credentials. Native file picker and progress keep familiar behaviour; status changes announce once per actual transition. No decorative motion or additional font is needed.

Inspected 1440px desktop and 360/366px mobile layouts. Finish review found one accessibility issue: processing transitions lacked live announcements and upload progress lacked a name. Fixed with a persistent polite region updated only when the status summary changes, plus a labelled progress element. Captures are in verification/guest-uploads. The unavailable design engine supplied no detector or direction board; review used the existing DESIGN.md/PRODUCT.md Harbour foundation.

Finish reviewer verified the accessibility fix and returned ship, with no remaining material fixes.
