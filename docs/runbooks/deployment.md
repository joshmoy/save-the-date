# Portable deployment contract

Three independently runnable Node 22.23.x processes: Next.js web, NestJS API, worker. PostgreSQL 16 supplies transactions, sessions, tenant records, job leases and migrations. An HTTPS reverse proxy exposes one public origin; the API is private to the gateway. Do not expose API port 4000 directly without equivalent TLS/origin/session protections. Static-only hosting is unsupported.

`docker compose up --build` is the provided local container profile, using private local volumes and capture-only email. Never use its development keys/passwords publicly. R0 API image built on a generic Linux container using the cached official Node 22.23.2 base; the default image is pinned to its manifest digest. Database-backed /api/v1/health passed from the container against the isolated local database. Native process startup passed too. Web public and .next/static assets are copied into the standalone tree during the supplied image build. Full web/worker compose startup and R1+ runtime dependencies still need rehearsal.

Production: supply DB_CONNECTION for a supported PostgreSQL host with verified TLS; PUBLIC_ORIGIN as HTTPS; API_INTERNAL_ORIGIN; TOKEN_HASH_KEYS from protected random secret material; production EMAIL_ADAPTER and sender credentials (or disabled); durable STORAGE_ROOT shared by API/workers or a tested object adapter; explicit RETENTION_POLICY/BACKUP_POLICY identifiers. Production configuration rejects capture email, development keys and /tmp storage. Config policy identifiers document operator intent, not implemented retention enforcement.

Run `pnpm db:migrate` once as an authorised release job with a recoverable backup. All replicas must share the same database and secrets. Mount storage directories writable by the Node runtime user. Never build secrets into images. Configure process restart, readiness on /api/v1/health and liveness checks independently. Restrict outbound access and least-privilege database/storage credentials. API readiness performs a real database query. Current health reports optional AI as disabled.

Before R3: finish provider contract tests, signing/encryption-key rotation, storage/media runtime checks, worker heartbeat metrics, renderer browser/font and FFmpeg dependencies, limits, security review, load tests and the complete restore drill. This foundation image is not an R3 production release.
