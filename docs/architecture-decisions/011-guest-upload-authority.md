# 011 — Guest upload authority

Upload grants and sessions use separate credential namespaces/cookies from private RSVP, shared website and admission. Dedicated grants bind one event and album; a valid household session may obtain upload access only to owner-enabled guest albums. All API and worker operations revalidate source grant, expiry, wedding and target album. Guest assets store upload-session provenance without creating a fake staff account.

Session attempt/byte allowances serialize before wedding quota reservation. Failed processing releases wedding storage but retains the attempt allowance as an abuse bound. Credentials expire and can be revoked without changing the canonical website URL.

ClamAV is a configurable adapter over its private INSTREAM protocol. Guest processing fails closed if safety scanning is absent, followed by bounded native format processing. Approval and publication remain independent. Invited publication comes from validated household access and immutable event snapshots, never upload possession.
