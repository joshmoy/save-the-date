# Invitation renderer and immutable exports

Use packages/templates for versioned schemas and one React-to-HTML card renderer shared by browser preview and export. Four version-one families are Royal elegance, Garden romance, Modern minimal and Photo story; curated locally licensed Cormorant, Lora and Source Serif 4 fonts preserve accents. Fixed 480×672 logical dimensions map to 5×7 inches, JPEG scale 3.125 and PDF 360×504 points. Colours inherit the current wedding palette unless explicitly overridden.

The API resolves authoritative wedding/event revisions and approved photo bytes; jobs store the immutable resolved design, photo/font checksums, renderer revision and canonical URL. Workers use a configurable Chromium adapter with outbound requests blocked, local fonts, readiness checks, bounded launch/render deadlines, field overflow validation and per-format completion. Recheck current requester/album/wedding permissions and job lease before committing private files. Provider-neutral private storage holds outputs.

Use explicit independent JPEG/PDF states and manual retries; retries reuse the snapshot. Stale warnings compare event/wedding/design revisions and unavailable photos. Downloaded invitation files never change when website drafts or publications change. Batch/personalised cards remain Later.
